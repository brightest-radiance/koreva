# Koreva: complete project (v6)

This is a complete project. Do NOT open the zip in Android Studio directly.

## Windows
1. Install Node.js (https://nodejs.org) and Android Studio.
2. Extract this zip. Extracting over your old Koreva folder is fine.
3. Double-click SETUP-AND-BUILD.bat and wait. It installs packages, creates the Android project, adds Koreva's native code and icons, and opens Android Studio.
4. When Gradle finishes: Build > Generate App Bundles or APKs > Generate APKs. Install the APK over your old app.

## Fedora and other Linux
Run ./setup.sh, then open the android folder in Android Studio (or build with ./gradlew assembleDebug).

## Web version for PC and Linux
The www folder is the web app. Host it (for example GitHub Pages) and install it from Edge, Chrome, Chromium or Brave.

## Home screen widget
Long-press the home screen > Widgets > Koreva.
