Koreva update 3
1. Copy the "android" and "www" folders from this zip onto your Koreva project folder (replace when asked).
2. In Command Prompt inside that folder:  npx cap sync android
3. Android Studio: Build > Generate App Bundles or APKs > Generate APKs. Install over the old app.
4. In the app: Train > Plan tools > Rebuild plan for my goal (old plans are not changed automatically).
5. Me > Download a backup now saves to Documents/Koreva on the phone and offers Share.
